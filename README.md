# ART inspired

Eine Website, die Kunstwerke aus der Metropolitan Museum of Art API durchsucht.

## Links

Live Website: https://www.im2.imulupaf.myhostpoint.ch/
GitHub Repository: https://github.com/faebsl/IM2_fabiacecchin_mmp25c1
API: https://metmuseum.github.io/?ref=freepublicapis.com

## Funktionen

- Suche nach Kunstwerken
- Filter nach Department, Zeitraum, Highlights und ausgestellten Werken
- Darstellung der Ergebnisse als Karten
- Lottie-Ladeanimation

## Verwendete API

The Metropolitan Museum of Art Collection API
